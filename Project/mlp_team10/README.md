## Option 1: Open directly in browser (no install needed)

Just double-click `index.html` — works immediately in any modern browser (Chrome, Edge, Firefox).

---

## Option 2: Build a .exe (Windows)

**Requirements:** Python 3.8+ installed (https://python.org)

**Steps:**
1. Open a terminal inside the `mlp_team10` folder
2. Run: `build.bat`
3. Wait ~1 minute for PyInstaller to finish
4. Find your EXE at: `dist\MLP_Team10.exe`
5. Double-click the EXE — it launches the website in your browser automatically

## What the website includes

- **Hero section** — animated live neural network
- **Architecture** — explains layers, neurons, weights, bias
- **Interactive Demo** — build & run your own MLP (5 architectures, 4 activation functions, live forward pass)
- **Training section** — trains on XOR problem, live loss curve, decision boundary, truth table
- **Limitations** — when MLP is not the right choice
- **Quiz** — 15 MCQs with instant grading and feedback
