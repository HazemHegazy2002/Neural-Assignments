Architecture

Inside an MLP

A Multi-Layer Perceptron stacks layers of neurons. Each neuron computes a weighted sum of its inputs, adds a bias, then passes the result through an activation function.

x
Input layer
Receives raw features — pixel values, sensor readings, numbers. One neuron per feature.
→
h
Hidden layer(s)
Learns patterns by combining inputs with learned weights. More layers = more complex patterns.
→
y
Output layer
Produces the final prediction — a class label, a probability, or a continuous value.
The core computation at every neuron
output = activation( w₁·x₁ + w₂·x₂ + … + wₙ·xₙ + b )
x = inputs w = weights (learned) b = bias (learned)

Limitations

When MLP struggles

🖼
Images & spatial data
MLP ignores spatial structure. CNNs use local filters and are far better for images.
→ Use CNN instead
📝
Sequences & text
MLP has no memory of previous inputs. RNNs and Transformers handle sequential data.
→ Use RNN/LSTM instead
📊
Small datasets
Many parameters mean MLP overfits easily when data is scarce. Regularization helps but only partially.
→ Use simpler model
🔢
Very high dimensions
Fully connected layers explode in parameter count with high-dimensional input (e.g. 1080p image).
→ Use feature extraction first
